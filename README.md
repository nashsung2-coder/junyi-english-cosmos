# 均一星辰宇宙 Junyi English Cosmos 詳細介紹

## 一、專案概述

**均一星辰宇宙(Junyi English Cosmos)**是一個以「宇宙星際探索」為主題的英文學習入口網站,為均一教育平台(Junyi Academy)的學習者、家長與教師打造。專案參考 [Cool English 星辰啟航](https://github.com/nashsung2-coder/cool-english-cosmos)的設計架構,將英文學習轉化為一場沉浸式的星際冒險:每一次學習都是一次探索,每一次進步都在星圖上發光。

網站的核心理念可以用一句話概括:

> 「用數據驅動成長、用遊戲激發熱情、用陪伴溫暖學習旅程。」

| 項目 | 內容 |
|---|---|
| 上線網址 | https://junyi-english-cosmos.pages.dev |
| 原始碼 | https://github.com/nashsung2-coder/junyi-english-cosmos |
| 部署平台 | Cloudflare Pages |
| 技術棧 | React 19 + TypeScript + Vite 7 + Tailwind CSS 4 + shadcn/ui + framer-motion |
| 設計風格 | 深空極簡主義(Deep Space Minimalism) |
| 頁面數 | 5 個主要頁面(大廳、專攻區、遊戲模式、家長區、教師區) |

## 二、設計理念

### 2.1 宇宙隱喻的教學設計

網站以「宇宙探索」作為貫穿全站的隱喻,將抽象的學習歷程具象化為可見的星際旅程。五維英文能力(聽力、口說、閱讀、寫作、字彙文法)被設計成「能力星雲」,六個學習面向是六顆「知識星球」,課程單元是通往星球的「遠征航線」。這種設計讓孩子從「要我去學」轉為「我想去探索」,利用探索慾望建立內在新動機。

### 2.2 學習 × 娛樂雙引擎

遊戲模式區分「學習遊戲」與「娛樂遊戲」兩個引擎:學習遊戲負責產生學習行為與獎勵(星幣),娛樂遊戲負責將獎勵轉化為情感連結(養寵物)。「學習 → 賺星幣 → 餵養裝備寵物 → 派寵物冒險 → 戰敗 → 回到學習變強」形成一個自我強化的正向循環,戰敗不是挫折,而是「回去學習」的溫柔提醒。

### 2.3 深空極簡主義視覺風格

全站採用宇宙深空黑(`#0B0F1E`)為基底,以均一品牌的星辰青(`#4ECDC4`)作為主色,星光金(`#FFD166`)點綴重要資訊。搭配玻璃擬態(glassmorphism)卡片、粒子漂浮動效、漸層光暈,營造出沉浸而不壓迫的太空探索氛圍。大廳頁以 AI 生成的星雲 Hero 圖與粒子背景開場,強化「進入宇宙」的第一印象。

## 三、五大區域詳細功能

### 3.1 大廳(Hall)— 你的英文宇宙

大廳是全站起點,由「星雲 Hero + 粒子動效 + 四大入口卡」構成。Hero 區以「你的英文宇宙,由你探索」為標語,向下捲動後呈現四張玻璃擬態入口卡,每張卡顯示該區域的即時狀態資訊:

| 入口 | 副標 | 狀態資訊 |
|---|---|---|
| 專攻區 | 學力之間 | 聽力 B1 ▲、字彙量 1,850 |
| 遊戲模式 | 學習 × 娛樂 | 能量條、排名 Top 100 |
| 家長區 | 親子星港 | 孩子 1 位、本週進度上升 |
| 教師區 | 班級指揮艙 | 班級 3 個、學生 87 位 |

### 3.2 專攻區(Specialty)— 數據驅動的成長地圖

專攻區採「左側功能欄 + 右側內容區」的非對稱布局,提供四種視角:

- **戰力**:五維能力雷達圖(聽力、口說、閱讀、寫作、字彙文法),以雷達圖視覺化呈現能力風景,搭配能力等級與字彙量統計。
- **技能樹**:六個技能分支(字母發音、單字、文法、聽力、閱讀、口說),每個技能節點顯示解鎖狀態與進度,點擊節點即進入均一平台的真實課程頁面。
- **今日任務**:每日五項學習任務,涵蓋影片觀看、聽力訓練、Jutor Speaking 跟讀、單字複習與知識遠征,完成可獲得經驗值。
- **成就勳章**:六枚勳章(聽力新星、連續 7 天、單字收藏家、口說冒險家、遠征隊長、滿分學者)記錄里程碑。
- **推薦資源**:12 個真實均一課程分類入口(英文學習專區、字母與發音、單字、文法、聽力、閱讀、寫作、生活情境、國小/國中/高中英文、Jutor AI 英語家教)。
- **學習資源**:8 大類 29 個具體課程卡,包含真實課程頁連結與深層錨點連結(例如文法時態錨點,可直接跳到分類區塊)。

### 3.3 遊戲模式(Game)— 學習 × 娛樂雙引擎

#### 學習遊戲:星幣的來源

- **六顆知識星球**:發音之星(90%)、字彙之星(72%)、聽力之星(55%)、文法之星(38%)、閱讀之星(25%)、口說之星(12%),每顆星球為可點擊卡片,點擊後直接進入均一對應的真實課程分類頁。
- **五場知識遠征**:

| 遠征 | 難度 | 內容 | 獎勵 |
|---|---|---|---|
| 字母叢林 | 新手 | 認讀 26 個字母與基本發音(15 題/10 分鐘) | +120 經驗值、狐狸貓餅乾 ×2 |
| 單字溪谷 | 簡單 | 食物、動物、家庭等主題單字(20 題/15 分鐘) | +180 經驗值、發光星塵 ×1 |
| 對話平原 | 中等 | 日常情境對話理解與練習(20 題/15 分鐘) | +220 經驗值、口說能量石 ×1 |
| 時態雪山 | 困難 | 現在式、過去式與進行式挑戰(25 題/20 分鐘) | +300 經驗值、稀有羽飾 ×1 |
| 閱讀星雲 | 困難 | 短篇故事理解與推理(25 題/25 分鐘) | +360 經驗值、智慧頭環 ×1 |

每場遠征的「出發遠征」按鈕皆連結至均一平台的真實課程頁。

#### 娛樂遊戲:純粹的寵物養成

- **狐狸貓夥伴「星塵」**:擁有親密度、快樂度、戰鬥力三項狀態,可撫摸互動。
- **星幣商店**:六項商品(狐狸貓餅乾、星雲牛奶、星光項圈、語音學士披風、智慧頭冠、能量藥水),使用學習賺取的星幣購買,戰鬥力不足會顯示提示。
- **夥伴冒險**:三場冒險關卡(單字森林偵察、語音峽谷探險、文法城堡攻防),每場有戰力需求;戰力不足時戰敗,系統彈出「去學習遊戲變強」的引導,回到學習遊戲形成動機循環。
- **與寵物聊天**:按鈕直接連結 [PlayGO](https://www.junyiacademy.org/playgo/home)(均一 AI 聊天夥伴,需登入均一),在站內即可進入真實的 AI 對話學習情境。

### 3.4 家長區(Parent)— 親子星港

家長區以溫暖陪伴為調性,包含五大模組:**成長摘要**(本週學習時長、完成課程數、獲得星幣的數字卡)、**能力風景**(五維能力的進步趨勢與雷達圖)、**親子共學艙**(親子共學建議與活動)、**成長相簿**(學習歷程紀錄)、**加油小棧**(給孩子的鼓勵訊息)。所有數字目前為情境示範值,設計上預留對接均一真實帳號資料的介面。

### 3.5 教師區(Teacher)— 班級指揮艙

教師區以教學管理為核心,包含:**班級戰情**(班級整體能力分布與趨勢)、**套餐工坊**(建立與派發學習套餐,對應均一的「套餐」學習指派機制)、**學生總覽**(學生名單與個人進度表格)、**榮譽殿堂**(班級里程碑與優秀表現表彰)。同樣預留對接均一教師後台資料的介面。

## 四、學習內容與真實連結

站內所有學習連結皆指向均一平台的**真實課程分類頁**,而非佔位連結:

| 模組 | 連結數 | 內容 |
|---|---|---|
| 推薦資源 | 12 個入口 | 英文學習專區、字母與發音、單字、文法、聽力、閱讀、寫作、生活情境、國小/國中/高中英文、Jutor AI |
| 學習資源 | 29 個課程卡 | 「認識字母 A」「字母的讀法」等具體課程,含深層錨點連結 |
| 知識星球 | 6 個 | 直接對應六個能力分類頁 |
| 知識遠征 | 5 個 | 各自對應的課程分類或錨點頁 |

這些連結是透過實際走訪均一平台(使用用戶瀏覽器登入)逐一收集核實的,確保點擊後能正確抵達對應課程頁面。

## 五、技術架構

### 5.1 前端技術棧

| 層級 | 技術 | 說明 |
|---|---|---|
| 框架 | React 19 + TypeScript | 元件化開發,型別安全 |
| 建構 | Vite 7 | 快速開發伺服器與生產建置 |
| 樣式 | Tailwind CSS 4 + 自訂 design tokens | 全站色彩、圓角、陰影以 CSS 變數統一管理 |
| 元件庫 | shadcn/ui | 按鈕、卡片、對話框、頁籤等互動元件 |
| 動畫 | framer-motion + CSS transitions | Hero 入場、卡片浮動、粒子背景、頁面轉場 |
| 路由 | wouter | 輕量客戶端路由(`//hall`、`/specialty`、`/game`、`/parent`、`/teacher`) |

### 5.2 專案結構

```
client/
├── public/
│   ├── assets/              # 生成圖片(Hero 星雲、Logo、星際地圖、吉祥物)
│   └── learning-resources.json  # 29 個學習資源資料(全站內容來源之一)
├── src/
│   ├── components/Navbar.tsx     # 全站導覽列(含假科目入口)
│   ├── const.ts                  # 341 行全站資料:入口、能力維度、星球、遠征、任務、勳章、商店、冒險、連結
│   └── pages/
│       ├── Home.tsx              # 轉址至大廳
│       ├── HallPage.tsx          # 大廳(粒子背景 + Hero + 四入口)
│       ├── SpecialtyPage.tsx     # 專攻區(雷達圖 + 技能樹 + 任務 + 資源)
│       ├── GamePage.tsx          # 遊戲模式(學習/娛樂雙模式 + 寵物養成)
│       ├── ParentPage.tsx        # 家長區
│       └── TeacherPage.tsx       # 教師區
```

### 5.3 部署流程

網站部署在 Cloudflare Pages(`junyi-english-cosmos` 專案),程式碼同步推送至 GitHub 倉庫(作者 nashsung <nashsung2@gmail.com>)。建置產物為 `dist/public`(Vite 輸出),透過 wrangler 手動部署;若於 Cloudflare 儀表板設定 Build command(`pnpm install && pnpm vite build`)與 Framework preset 為 None,即可啟用 GitHub 自動建置部署。

### 5.4 圖片處理

Hero 背景、Logo、星際地圖、吉祥物等視覺素材由 AI 生成後,壓縮為 JPG 存放於 `client/public/assets/`,隨專案倉庫與 Cloudflare 建置一起部署,確保任何環境(包括 GitHub 自動建置)都能正常顯示。

## 六、網站導覽列

全站頂部固定導覽列包含三層入口:

| 層級 | 內容 | 行為 |
|---|---|---|
| 主要入口 | 大廳、專攻區、遊戲模式、家長區、教師區 | 正常跳轉至各頁 |
| 科目 | 國文、英文、數學、自然、社會、生活、藝術、健康 | 假的入口,點擊顯示「功能規劃中,敬請期待!」 |

## 七、未來擴充方向

以下為建議的後續迭代方向,可依需求逐步實作:

1. **進度持久化**:將星幣、親密度、裝備等狀態存入 localStorage,重新開啟頁面進度不消失。
2. **視覺換裝**:購買裝備後寵物圖片即時更換造型,提升養成成就感。
3. **遠征小測驗**:為五場遠征加入 5 題快速問答,答對才給星幣,再導向均一深度課程。
4. **已學習標記**:星球/遠征/資源卡加上完成勾選(存於 localStorage)。
5. **科目擴充**:複製英文區資料結構,填入數學、自然等真實課程連結。
6. **真實資料介接**:對接均一帳號 API,讓能力雷達圖、任務進度、班級數據動態化。
7. **每日一句英文**:首頁每日更換一句英文並附發音按鈕,增強每日回訪動機。
